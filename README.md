# HS Blog

> 기억하기 위한이 아닌 "기억하지 않기 위한 기록"

HS Blog는 생각, 기술, 작업 기록을 담은 개인 블로그 입니다.
이 저장소는 Quartz로 만든 개인 블로그 사이트의 소스입니다.

🔗 방문하기: https://haksoo0918.github.io/blog

## 소개

- 개인적인 생각과 메모 정리
- 기술 학습과 작업 기록
- 지속적으로 조금씩 계속 수정중

## 기술

- obsidian
  - 참고: https://obsidian.md/ko/help/
- quartz5
  - 참고: https://quartz.jzhao.xyz/

## 실행

```
npm run dev
```
