## 1. 전 과정 프로세스 요약

```
[1단계: 기획 & 검증] ──► [2단계: 데이터 설계] ──► [3단계: UI/UX 설계]
   (서비스 정의)           (화면 기반 DB)          (심플 디자인 시스템)
                                                        │
[6단계: 운영 & 확장] ◄── [5단계: 통합 & 배포] ◄── [4단계: 모듈 개발]
   (유지보수 & 개선)        (Vercel + QA)           (Cursor + Supabase)
```

## 2. 단계별 상세 과정 & AI 활용법

### 1단계: 아이디어 구상 및 기획 검증 (Planning & Validation)

"무엇을 만들 것인가"를 정의하고, 기획의 구멍과 예외 케이스(Edge Case)를 사전에 메우는 단계입니다. 모든 화면을 기획할 필요 없이 **핵심 기능 화면 2~3개**만 정의합니다.

- **실행 작업:**
    
    1. 서비스 핵심 목적 및 유저 흐름(User Flow) 정의.
    2. 주요 화면 목록 3~4개 선정 (예: 메인 리스트, 상세 보기, 작성 폼).
    3. AI를 통한 UX 비판적 검수 (예외 상황 도출).
        
- **AI 활용 프롬프트:**
    
    > _"개발자용 사이드 프로젝트 팀원 모집 서비스를 MVP로 만들려고 해. 메인 목록, 상세 정보, 팀원 지원 폼 3개 화면으로 구성할 때, 기획적으로 놓치기 쉬운 예외 상황(예: 이미 마감된 글에 접근, 중복 지원 등)을 비판적으로 도출해줘."_
    

### 2단계: 데이터 및 API 흐름 설계 (Data Architecture)

화면을 그리기 전, **어떤 데이터가 저장되고 이동해야 하는지** 구조를 세웁니다. 데이터 흐름이 정립되어야 AI가 개발 단계에서 엉뚱한 코드를 짜지 않습니다.

- **실행 작업:**
    
    1. 기획한 화면에 표시될 정보 항목(Text, Image, ID 등) 추출.
    2. 유저가 입력할 데이터(Form Data) 목록화.
    3. DB 테이블 간의 관계(1:N, N:M) 정의.
        
- **AI 활용 프롬프트:**
    
    > _"위 화면들에서 추출한 데이터는 다음과 같아: [유저 정보, 글 제목, 모집 분야, 지원 내역]. Supabase(PostgreSQL)에서 사용할 수 있는 DB 테이블 스키마(SQL)와 연관 관계(Foreign Key)를 작성해줘."_
    

### 3단계: UI/UX 화면 설계 및 레이아웃 (Design & Component)

선호하시는 '심플한 디자인'을 유지하면서, 퍼블리싱 및 프론트엔드 연동에 최적화된 컴포넌트를 구성합니다.

- **실행 작업:**
    
    1. Relume/v0를 통한 화면 와이어프레임 구조 잡기.
    2. Figma로 가져와 폰트, 컬러 토큰, 기본 버튼/입력창 컴포넌트화.
    3. AI 히트맵 도구로 버튼 시인성 및 UX 흐름 시각적 검증.
        
- **AI 활용 방식:**
    
    - **Relume AI:** 텍스트 아이디어 기반으로 와이어프레임을 생성해 Figma 컴포넌트로 추출.
    - **v0.dev:** 요구사항을 입력해 Tailwind CSS 기반 UI 레이아웃 코드 초안 즉시 생성.

### 4단계: 모듈 단위 개발 & BaaS 연동 (Frontend & Backend Development)

전체 코드를 한 번에 생성하지 않고, **기능 단위(모듈/컴포넌트)로 쪼개어 개발**합니다. 백엔드는 개발 부담을 없애기 위해 **Supabase**를 활용합니다.

- **실행 작업:**
    
    1. Next.js 기반 프로젝트 생성 및 Supabase 클라이언트 세팅.
    2. 퍼블리싱 강점을 살려 UI 레이아웃 구조 세팅 (Tailwind CSS / Shadcn UI).
    3. Cursor IDE를 이용해 데이터 호출(API) 및 상태 관리(State) 로직을 모듈별 작성.
        
- **AI 활용 프롬프트 (Cursor 내):**
    
    > _"Supabase Client를 활용해 `posts` 테이블에서 최신순으로 글 10개를 불러오는 React 커스텀 훅(`useFetchPosts`)을 TypeScript로 작성해줘. 로딩 상태와 에러 처리도 포함해줘."_
    

### 5단계: 서비스 통합, QA 및 첫 배포 (Integration & Deployment)

로컬 환경을 벗어나 **실제 사용자가 접속 가능한 환경**에 서비스를 올리고 테스트합니다.

- **실행 작업:**
    
    1. Vercel과 GitHub을 연동하여 자동 배포(CI/CD) 구축.
    2. 스마트폰, PC 등 실제 기기에서 접속하여 UI 및 반응형 검수 (퍼블리셔의 직접 검수).
    3. AI에게 통합 테스트 코드 및 보안 점검 요청.
        
- **AI 활용 프롬프트:**
    
    > _"이 작성 폼 Component의 TypeScript 코드에 XSS 공격이나 메모리 누수 위험이 있는지 검토하고, 올바른 예외 처리 코드를 보완해줘."_
    

### 6단계: 운영, 유지보수 및 기능 확장 (Maintenance & Evolution)

실제 유저 피드백을 수집하고, 코드 품질을 유지하며 기능을 단계적으로 추가합니다.

- **실행 작업:**
    
    1. 사용자 오류 제보 수집 및 버그 수정.
    2. AI를 활용한 기존 코드 리팩토링 및 주석/문서화.
        
- **AI 활용 프롬프트:**
    
    > _"이 기존 컴포넌트 코드의 성능을 최적화(useCallback/useMemo 활용)하고, 나중에 내가 유지보수하기 쉽도록 각 기능 단위로 상세 주석을 달아줘."_
    

## 3. 단계별 추천 AI 도구 및 역할 총정리

|**단계**|**추천 도구 / 서비스**|**주요 역할 및 특징**|
|---|---|---|
|**기획 & PRD**|**Claude 3.5 Sonnet / ChatGPT**|비즈니스 로직 검증, 예외 케이스 도출, PRD 작성|
|**UI/UX 구조**|**Relume AI**|사이트맵 및 Figma 연동 와이어프레임 자동 생성|
|**UI 코드 생성**|**v0.dev**|Tailwind CSS + Shadcn UI 기반 프론트엔드 코드 생성|
|**디자인 검증**|**Attention Insight**|AI 기반 유저 시선 추적(Heatmap) 및 시인성 분석|
|**개발 (IDE)**|**Cursor IDE**|전체 프로젝트 맥락 기반 고성능 모듈 단위 코딩|
|**백엔드/DB**|**Supabase**|DB, 회원가입/로그인(Auth), 파일 저장소 해결 (BaaS)|
|**호스팅/배포**|**Vercel**|Git 연동 한 번으로 클릭 한 번에 웹 배포 및 SSL 제공|

## 4. 핵심 수칙 3가지

1. **아키텍처와 UI 레이아웃은 직접 제어한다**
    
    - CSS와 반응형 구조는 퍼블리셔의 감각으로 직접 잡고, AI에게는 "Supabase 데이터 연동 로직"이나 "복잡한 JS 상태 변경 코드"를 맡기세요.
        
2. **"한 번에 한 파일만" 작성하게 한다**
    
    - 프로젝트 전체를 만들어달라고 하지 말고, `UserCard.tsx`, `useAuth.ts`처럼 파일 단위를 명확히 지정해 요청해야 코드가 꼬이지 않습니다.
        
3. **배포는 초반에 끝낸다**
    
    - 개발 첫날 Vercel 배포 주소를 만들어 두고, 수정할 때마다 실제 스마트폰으로 들어가 보면서 화면을 점검하는 루틴을 만드세요.
