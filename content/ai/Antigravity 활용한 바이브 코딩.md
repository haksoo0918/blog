### 1. 역할 분담: 큰 그림은 Antigravity 2.0, 디테일은 IDE

- **Antigravity 2.0 (데스크톱 앱)**: **기획, 아키텍처 토론, 시스템 모니터링**에 활용하세요.
    - 채팅창에서 넓은 시야로 `/grill-me` 인터뷰를 진행하고, `PRD.md` 및 `architecture.md`를 함께 보면서 전체 설계의 뼈대를 완성합니다.
- **Antigravity IDE (에디터 창)**: **실제 구현 검토와 미세 조정**에 사용하세요.
    - AI가 작성해 준 코드 중 마음에 안 드는 특정 함수가 있다면, 드래그한 뒤 **`Ctrl + I` (Inline Command)** 를 눌러 그 부분만 콕 집어 _"여기 이 예외 처리 추가해줘"_, *"비동기 처리로 바꿔줘"*와 같이 부분 편집을 지시하는 것이 훨씬 빠르고 정확합니다.

---

### 2. `@` 멘션 기능으로 완벽한 컨텍스트 전달하기

바이브 코딩의 핵심은 **AI에게 무엇을 봐야 하는지 정확히 알려주는 것**입니다. 채팅창에 `@`를 입력하면 다양한 컨텍스트를 쉽게 첨부할 수 있습니다.

- `"이 파일 고쳐줘"` 대신 👉 **`@index.js` 이 파일에서**
- `"터미널 에러 해결해줘"` 대신 👉 **`@Terminal-1` 세션의 에러 수정해줘**
- `"예전에 나눈 규칙 기억해?"` 대신 👉 **`@이전대화` 에서 정의한 방식 적용해줘**
- AI가 컨텍스트를 완전히 쥐고 있으므로 엉뚱한 코드를 짜는 실수가 90% 이상 줄어듭니다.

---

### 3. 기획이 막힐 땐 `/grill-me` (인터뷰 모드) 호출

앱을 만들기 시작할 때 기획서에 빠진 구멍이 많으면 개발 중에 계속 삐걱거리게 됩니다.

- 기획을 대략 구상한 뒤 안티그라비티 채팅창에 **`/grill-me`** 를 입력하세요.
- AI가 면접관이 된 것처럼 나에게 질문을 던집니다. (예: _"이 앱의 핵심 기능 3가지는 무엇인가요?", "사용자 인증은 소셜 로그인으로 하나요?"_)
- 3~4번의 핑퐁 대답만으로도 아주 견고하고 촘촘한 `PRD.md`가 뚝딱 작성됩니다.

---

### 4. 최신 기술 문서는 `/browser`로 읽히기

AI는 가끔 예전 버전의 라이브러리 함수나 사양을 사용해 코드를 짜서 에러를 내곤 합니다.

- 외부 API나 새로운 프레임워크를 사용한다면 꼭 **`/browser`** 혹은 **`@https://공식문서주소`** 를 던져주고 시작하세요.
- 예: `/browser https://playwright.dev/docs/intro 라이브러리 사용법을 먼저 읽고 내 코드에 크롤링 예제 추가해줘.`
- AI가 공식 문서 사이트의 최신 API 문서를 크롤링해서 실시간으로 읽은 뒤 정확한 최신 문법으로 코드를 작성해 줍니다.

### 5. `Visual Diff`와 `Auto-Fix`로 안전한 디버깅

- **비교하며 승인**: AI가 코드를 고치면 IDE 화면에 빨간색/초록색 **Visual Diff Overlay**가 뜹니다. 무조건 적용하지 말고, 바뀐 부분을 눈으로 쓱 훑어보며 마음에 드는 변경사항만 `Accept(승인)` 하세요.
- **에러 자동 수정 (Diagnostic Auto-Fix)**: 코드가 빌드가 안 되거나 터미널에 빨간색 에러 로그가 찍히면, 에러가 난 코드 렌즈 위에 뜨는 `Auto-Fix` 버튼을 클릭하세요. AI가 에러 로그와 소스코드를 대조하여 즉시 원인을 찾고 알아서 고쳐줍니다.
